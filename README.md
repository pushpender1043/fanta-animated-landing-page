# 🍊 Fanta Animated Landing Page

A highly interactive and visually appealing product landing page featuring complex scroll animations and parallax effects.

**🚀 Live Demo:** [fanta-webpage-xi.vercel.app]

**🛠️ Tech Stack**
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Animation Library:** GSAP (GreenSock), ScrollTrigger

**✨ Key Features**
* **Scroll-Triggered Animations:** Smooth, high-performance animations tied to user scroll behavior using GSAP.
* **Modern UI:** Clean, responsive design matching brand aesthetics.
* **Organized Architecture:** Clean separation of concerns with dedicated CSS, JS, and image assets.

**💻 Local Setup**
1. Clone the repository: `git clone https://github.com/pushpender1043/fanta-animated-landing-page.git`
2. Open `index.html` in your browser.
